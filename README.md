## 📖 Sobre o Projeto

O **Jogo do Número Secreto** é uma aplicação onde o usuário deve adivinhar um número gerado aleatoriamente pelo sistema.

A cada tentativa, o jogo informa se o número secreto é maior ou menor que o valor digitado, auxiliando o jogador até encontrar a resposta correta.

Esta versão foi desenvolvida para praticar os primeiros conceitos de programação utilizando JavaScript e compreender o funcionamento da lógica por trás da aplicação.
